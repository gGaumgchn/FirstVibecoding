# 贪吃蛇游戏

一个使用Python和Pygame库实现的经典贪吃蛇游戏。

## 功能特点

- 🎮 完整的贪吃蛇游戏体验
- 🎯 键盘方向键控制
- 📊 实时分数显示
- 🎨 简洁的图形界面
- 🔄 游戏结束后可重新开始
- ✨ 支持本地离线游玩

## 安装和运行

### 1. 安装依赖

首先需要安装pygame库：

```bash
pip install pygame
```

### 2. 运行游戏

在项目目录下运行：

```bash
python snake_game.py
```

### 3. 游戏控制

- **方向键**：控制蛇的移动方向（上、下、左、右）
- **R键**：游戏结束后重新开始
- **Q键**：退出游戏

### 4. 游戏规则

- 蛇会自动向前移动
- 吃到红色食物得分并变长
- 撞墙或撞到自己会导致游戏结束
- 每个食物得10分
